# Hamda Jama Yousuf — Academic Portfolio

A responsive, static academic website (HTML, CSS, JavaScript). Designed for free hosting with GitHub Pages.

## Preview locally
Open `index.html` in your browser.

## Publish using GitHub Pages
1. Sign in at https://github.com and create a **public** repository named `YOUR-USERNAME.github.io` (replace `YOUR-USERNAME` with your actual GitHub username).
2. Upload `index.html`, `style.css`, `script.js`, and `profile-photo.jpg` to the repository root and commit.
3. Go to **Settings → Pages**. Under **Build and deployment**, choose **Deploy from a branch**, `main`, and `/ (root)`, then save.
4. After deployment, visit `https://YOUR-USERNAME.github.io/`.

## Before sharing publicly
- Replace placeholder LinkedIn link with your real profile URL.
- Check professional role descriptions and publication metadata against original sources.
- Add your portrait only if you want to publish it.
- Add your CV PDF only after checking it for private contact details.
- Add additional verified publications, conference contributions, and projects.

No backend or paid hosting is required.

## Certificates section
The website includes a **Certificates & Credentials** section and a file picker for **local previews only**. Choosing files does not upload or permanently add them to the site.

To publish real certificates, provide the PDF/JPG/PNG files, the exact credential title, issuer, and year. They can then be added to a `certificates/` folder with permanent cards/links in `index.html`. Never publish private certificate IDs, personal phone numbers, or other sensitive details without checking.
